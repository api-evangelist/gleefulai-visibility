# Visibility (GleefulAI) — merged into `gleefulai`

This profile was a **duplicate**. It is retired as of 2026-08-11 and its pages
now redirect to the surviving profile.

**Go to: https://github.com/api-evangelist/gleefulai** —
[apis.io/providers/gleefulai/](https://apis.io/providers/gleefulai/)

## What happened

One submission through apis.io/add was answered twice, two days apart, and each
reply created a repository — this one on 2026-08-02 and `gleefulai` on
2026-08-04 ([apisio/apis.io#45](https://github.com/apisio/apis.io/issues/45)).
Both went live, so a single company was published as two providers, with two
scores and two listings.

Nothing was lost in the merge. Both profiles described the same 17 APIs derived
from the same live OpenAPI at `visibility.gleefulai.com` — identical 22 paths, a
byte-identical screenshot, an identical `llms.txt`. `gleefulai` survived because
it is deeper: 7 artifact directories against 4, and the only one of the pair
carrying authentication, finops and plans.

Redirects are registered in the API Evangelist network's `retired.yml`, so every
URL this profile published now resolves to its equivalent on `gleefulai`.
